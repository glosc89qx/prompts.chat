# Awesome ChatGPT Prompts

This repository contains a collection of ChatGPT prompt examples to get the best out of ChatGPT and other LLMs.

## How to Use

1. Browse the prompts in `prompts.csv` or below.
2. Copy the prompt into your chat session.
3. Start interacting with the model.

## How to Contribute

1. Fork this repository.
2. Add your prompt to `prompts.csv` using the `"act","prompt"` format.
3. Verify and test your prompt before submitting.
4. Submit a Pull Request.
